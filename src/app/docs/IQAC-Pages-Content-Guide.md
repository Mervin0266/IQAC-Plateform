# IQAC Platform - Detailed Page Content Guide

## 1. Academic Programs & Curriculum

### Purpose
Track and manage all academic programs, their curriculum details, and quality metrics.

### Key Sections
- **Program Overview Cards**
  - Program name, code, department
  - Duration, intake capacity
  - Accreditation status
  - Quality rating/score

- **Curriculum Management**
  - Course structure and syllabus
  - Learning outcomes mapping
  - Faculty assignment
  - Credit distribution charts

- **Program Analytics**
  - Student enrollment trends
  - Pass percentage statistics
  - Industry feedback scores
  - Graduate employment rates

### Data Requirements
- Program details (name, code, department, duration)
- Course information (syllabus, credits, prerequisites)
- Faculty assignments
- Student performance data
- Industry feedback
- Accreditation documents

### Features
- Add/edit program information
- Upload curriculum documents
- Track program-wise quality metrics
- Generate program reports
- Compare programs performance
